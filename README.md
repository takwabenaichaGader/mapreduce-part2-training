# MapReduce — Think Like a Data Engineer

Site statique d'entraînement associé à la **Partie 2 — Hadoop, HDFS et MapReduce**.

## Contenu

- 30 exercices progressifs, du rappel Block/InputSplit jusqu'aux missions intégratrices.
- Réponses courtes, champs clé/valeur, QCM ciblés, simulations Map/Shuffle/Reduce et cas métier.
- Cas fil rouge NYC Yellow Taxi + contextes e-commerce, logs Web et IoT industriel.
- Indices, correction immédiate dès qu’une réponse est erronée, solution expliquée et diagnostic par notion.
- Mode **Réviser mes erreurs**.
- Progression enregistrée avec `localStorage`.
- Aucun backend, aucune dépendance externe.

## Utilisation locale

Double-cliquer sur `index.html` suffit.

Pour tester via un petit serveur local :

```bash
python -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.

## GitHub Pages

1. Créer un dépôt GitHub public.
2. Envoyer **le contenu de ce dossier** à la racine du dépôt (`index.html`, `style.css`, `app.js`, `data/`, `assets/`).
3. Ouvrir **Settings → Pages**.
4. Choisir **Deploy from a branch**.
5. Sélectionner `main` et `/ (root)` puis **Save**.
6. Attendre la publication de l'URL GitHub Pages.
